KiCad completion procedure

What opens locally

Start with hardware/kicad/zudo-scope10-p0.kicad_pro. The root schematic links ten child sheets: power, module interfaces, acquisition, five dual-input pages and two control pages. All selected pin mappings and values come from design/circuit.json, generated by scripts/make_design.py. There are 224 physical instances in the draft and 134 named nets.

The symbols are intentionally pin-complete rectangular review symbols. They are not polished conventional circuit drawings. The text netlist and design/connections.csv provide an independent review surface. Global labels carry inter-sheet connections. The host checks compare generated pin/net memberships; they are not native KiCad ERC.

The .kicad_pcb is only a 250 × 180 mm rectangular outline, with no footprints or tracks. Do not manufacture it. Mechanical mounting holes listed in the requirements are proposals and are not drilled in that outline.

Required work before placement

  1. Reacquire and visually review the exact display schematic/CAD and NKK switch drawing. Resolve all physical pin identities, including duplicated PJ-313 terminals.
  2. Select actual MPNs and supplier codes for resistors, capacitors, fuse and four module-header strips. The passive resistor tolerances, voltage ratings and capacitor dielectrics are constraints, not interchangeable generic labels.
  3. Verify every symbol pin to actual footprint pad. The locally supplied XUNPU footprint is drawing-derived, not independently approved. Generic SOIC/TSSOP/SOT package names are candidates, not evidence of exact footprint correctness.
  4. Confirm the Pico and display socket heights, component face, mirrored row numbering, module service clearance, USB access and control panel stack. Exact display hole/connector geometry is still unavailable here.
  5. Open all generated files in the current KiCad, fix any native format issues, save, run ERC and reconcile every electrical finding with the source specification. Preserve project-generated evidence and report native tool/version/results.

Routing guidance

Use a continuous low-impedance ground reference under signal and digital circuits; do not automatically split the ground plane and force return currents across gaps. Separate the LCD/SPI and backlight return paths spatially from biased input nodes and reference distribution. Place each amplifier's 100 nF bypass at its supply pins. Keep the 1 MΩ / 200 kΩ / 249 kΩ high-impedance node compact and clean, with the clamp and first capacitor close to the input amplifier.

Keep the mux-common traces short; place the three post-mux buffers and ADC RC networks near their loads. Treat display clock, address edges and source-series resistors as a coupled noise/settling problem. Run representative worst-case pattern tests with the display active as well as dark.

The four-layer, 1.6 mm board is a starting point for grounding and routing convenience, not a paid fabrication stackup. Confirm assembler-supported layer/copper/thickness options and actual mechanical constraints before locking it. A later compact or two-layer cost-down is a separate layout qualification.

Release sequence

After native ERC, placement and routing, refill planes and run DRC, schematic-to-PCB parity, pin-map checks and mechanical review. Export Gerbers, drill, assembly BOM, CPL and STEP only from that reviewed revision. Review JLC's placement rendering and obtain written assembly acceptance for every fitted line. Archive the exact exported bytes and checksums. manufacturing/release_guard.py blocks release while any gate remains open; it does not replace engineering review.

Pre-layout evidence. No factory approval or hardware measurements are implied.
