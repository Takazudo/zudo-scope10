What this package is

zudo-scope10 is the ten-input waveform monitor, separated from the five-oscillator instrument. “LED” in the request is interpreted as the LCD/display project. The LED-lamp repository supplies the documentation pattern, not the circuit.

This release is a pre-layout engineering handoff. It contains a specified circuit, native schematic drafts, analytical calculations, control/UI prototype, selected component evidence, firmware core tests and manufacturing instructions. It does not contain a completed routed PCB, verified Gerbers, production CPL, completed LCD firmware or an approved order.

The first hardware build

Use one factory-populated custom carrier, one factory-headered Raspberry Pi Pico H, and one preassembled Waveshare Pico-ResTouch-LCD-3.5 (SKU 19907). Keep ten independent inputs, ten TIME pots and ten three-position RANGE switches. One LCD shows ten panes at once.

No soldering at home is required or assumed. All PCB components, including through-hole controls, connectors and headers, belong on the factory BOM. Modules are plugged into already-soldered connectors with power off. Any needed electrical repair goes to the assembler or a contracted rework service.

Local sequence

  1. Run python3 scripts/validate.py from the project root. This checks the data and generated files, not electrical safety.
  2. Run python3 scripts/serve.py, then browse http://127.0.0.1:8000/. The offline catalogue and UI simulation work without npm packages.
  3. Read the power/interface gates and the component pin maps before opening hardware/kicad/zudo-scope10-p0.kicad_pro.
  4. Resolve the display module's power/header revision and the physical jack, switch, socket and cap drawings before finishing footprints or placement.
  5. Complete local KiCad review, layout, ERC/DRC and assembly review. Do not order the outline-only .kicad_pcb.

The documentation can be read immediately as Markdown. The included doc/ contains native zudo-doc configuration and MDX content. Use scripts/bootstrap_doc.sh to obtain the official scaffold in a new directory when you prefer that route. No repository, online document or order has been modified.

Pre-layout evidence. No factory approval or hardware measurements are implied.
